Getting Started

Welcome! This tool detects Acacia trees in your drone images using deep learning models that are trained to identify Acacia trees from drone aerial imagery. It then geolocates and pins each detection to a real-world location on the map.

What you need

Drone images, with their original metadata intact, the required information are GPS coordinates, focal length and gimbal orientation.

What happens

A deep-learning model outlines every Acacia tree it detects, then converts those pixels into latitude and longitude using geolocation technique usingthe drone's altitude, orientation and heading.

Tip: Upload the original files. Resizing, screenshotting or re-exporting strips the image metadata needed for geolocation.

Instruction

1. Prepare configuration settings for Acacia detection and geolocation

2. Upload your image files with the correct drone metadata

Note: Image metadata needs to be in EXIF format and include GPS coordinates and flight orientation

3. Click "Run" to start performing Acacia detection and geolocation
